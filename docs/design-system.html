Dish Passport

The design system, rendered from the app's real tokens. One accent, functional neutrals, a separate dark palette, an Inter type scale, and a flavor palette that's the product's signature — the ten taste dimensions are first-class color.

Material-3 aligned · cross-platform (Expo) · source: src/theme/tokens.ts

01

Color — roles

One accent (paprika) reserved for action and active state — never decoration. Neutrals carry a warm bias toward the ink, so nothing reads as default grey. Dark mode is a separate semantic palette, not an inversion.

02

Color — the flavor palette

The ten flavor dimensions are first-class tokens. Each has one fixed base; the chip tint and ink are derived by formula (base mixed 88% with paper; base darkened 25%) so the spectrum bar, chips, and lollipop list always agree. This is the thing no other app has.

Canonical order: umami · spicy · sour · sweet · bitter · rich · herbaceous · smoky · fermented · fresh

03

Type — Inter, one family

A single grotesk everywhere (Inter — Roboto's cross-platform stand-in). Hierarchy comes from size and weight, never colored boxes. Two weights per surface (Regular 400 + Semibold 600); Bold 700 is reserved for the wordmark. Ratio scale ≈1.25.

04

Spacing — the 8 pt grid

Every margin, pad, and gap is one of these seven values (4 for tight spots, 8 as the base unit). Pick from the scale, never in between — the consistency is what reads as designed. Minimum tap target is 48 dp (Material) / 44 pt (HIG).

05

Radius & elevation

Corners round at 8 / 12 / 16 and pill. Elevation stays deliberately near-flat — two soft shadow tokens only; the warm palette wants air, not drop-shadows.

06

Motion — spring, short, physical

The one layer the app doesn't have yet — this section is the spec the implementation targets. Springs (not linear easing), settling in 180–380 ms. Tap a swatch to feel press; enter loops on its own.

Reanimated withSpring configs; falls back to Material emphasized easing cubic-bezier(.2,0,0,1) where a spring doesn't fit. Respects reduced-motion.
